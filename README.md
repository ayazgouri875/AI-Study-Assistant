## 🚀 Features

- Interactive chatbot
- Conversation memory
- System prompts
- Environment variable support (.env)
- Error handling
- Clean project structure

## 🛠️ Technologies Used

- Python
- Google Gemini API
- python-dotenv
- Git & GitHub

## ▶️ How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Create a virtual environment

```bash
python -m venv venv
```

3. Activate it

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

4. Install dependencies

```bash
pip install -r requirements.txt
```

5. Create a `.env` file

```
GEMINI_API_KEY=YOUR_API_KEY
```

6. Run

```bash
python main.py
```
